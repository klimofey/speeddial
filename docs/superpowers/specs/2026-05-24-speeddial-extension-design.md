# SpeedDial — дизайн-документ

**Дата:** 2026-05-24
**Статус:** утверждён к планированию

## 1. Цель и принципы

Бесплатное Chrome-расширение, заменяющее новую вкладку красивым, быстрым и удобным
speed dial. Главные принципы:

- **Приватность по умолчанию.** Никакой рекламы, аналитики и скрытой телеметрии.
  Внешние запросы происходят только по явному действию пользователя (подгрузка
  картинки по введённой им ссылке или включённый вручную скриншот-сервис).
- **Скорость.** Новая вкладка должна открываться мгновенно. Лёгкий стек, без
  тяжёлых рантаймов, минимум работы при старте.
- **Современность и удобство.** Drag-and-drop карточек, превью, темы, настройка фона.

## 2. Технический стек

- **Manifest V3.** Замена новой вкладки через `chrome_url_overrides.newtab` →
  `index.html`. Страница получает осмысленный `<title>`.
- **Preact + Vite.** Компонентный UI (~4 КБ рантайма), JSX и хуки.
- **@crxjs/vite-plugin.** Собирает проект под MV3: не инлайнит скрипты (это
  нарушило бы строгий CSP расширений), обрабатывает `manifest`, даёт HMR в дев-режиме.
- **SortableJS** (MIT, ~10 КБ) — drag-and-drop сетки карточек.
- **fflate** (MIT, ~8 КБ) — упаковка/распаковка ZIP для экспорта/импорта.
- **TypeScript** во всех модулях.
- **Vitest** + `@testing-library/preact` — тесты.

### Разрешения (manifest permissions)

- `storage` — хранение данных.
- `unlimitedStorage` — снять лимит `storage.local` для картинок/фонов.
- `favicon` — иконки сайтов через MV3 favicon API
  (`chrome.runtime.getURL('/_favicon/?pageUrl=...&size=...')`).
- **Никаких** широких `host_permissions`.

### CSP

Опираемся на дефолтный строгий CSP расширений (`script-src 'self'
'wasm-unsafe-eval'; object-src 'self'`). Не ослабляем его. Remote-картинки
(`img-src`) не ограничены этим минимумом, поэтому подгрузка превью по URL и
опциональный скриншот-сервис (§5) работают через `<img src>` без широких
`host_permissions` и без CORS.

## 3. Архитектура

### Точки входа

- `manifest.json` (через `manifest.config.ts` для crxjs) — MV3, newtab override,
  разрешения выше.
- `index.html` + `src/main.tsx` — монтирование Preact-приложения.

### Компоненты UI (`src/components/`)

- **`<NewTab>`** — корневой layout: фон, шапка, поиск, сетка. Загружает состояние
  из storage при старте.
- **`<Clock>`** — часы, дата, приветствие по времени суток.
- **`<SearchBar>`** — поиск через выбранный движок (Google / DuckDuckGo / Bing) +
  мгновенный локальный фильтр карточек по названию/URL.
- **`<DialGrid>`** — сетка карточек, инициализирует SortableJS на контейнере и
  синхронизирует новый порядок обратно в состояние после drop.
- **`<DialCard>`** — одна карточка: превью, название, контекстное меню
  (изменить / удалить). Реализует каскад превью (см. §5).
- **`<CardEditor>`** — модалка добавления/редактирования: URL, название, выбор
  источника картинки (фавикон / буква+цвет / загрузка файла / ссылка на картинку).
- **`<Settings>`** — панель настроек: темы, фон, движок поиска, размер карточек,
  часы вкл/выкл, экспорт/импорт.
- **`<ThemePicker>`** — выбор встроенной темы и создание/редактирование своих.

### Модули логики (`src/lib/`)

- **`storage.ts`** — единственная обёртка над `chrome.storage`. Разделяет данные:
  метаданные → `sync`, бинарь → `local`. Экспорт/импорт снимка. Обработка квот.
- **`themes.ts`** — три встроенные темы + пользовательские. Применение через
  CSS-переменные на `:root`.
- **`images.ts`** — получение фавикона (MV3 favicon API), загрузка картинки по URL
  с кэшированием в `local`, обработка загруженного файла (в data URL / blob),
  опциональный скриншот-сервис (§5), каскад фолбэков.
- **`state.ts`** — общее состояние (карточки, настройки, активная тема) через
  Preact-контекст. Подписка на изменения storage между вкладками.
- **`backup.ts`** — сборка снимка, JSON- и ZIP-сериализация (fflate), валидация и
  восстановление при импорте.

## 4. Модель данных

```
// storage.sync (лёгкое, синхронизируется между устройствами)
settings: {
  schemaVersion: number,
  activeThemeId: string,
  customThemes: Theme[],
  searchEngine: 'google' | 'duckduckgo' | 'bing',
  cardSize: 'sm' | 'md' | 'lg',
  showClock: boolean,
  greetingName: string | null,
  background: { type: 'theme' | 'color' | 'gradient' | 'imageRef', value: string }
}
dials: Array<{
  id: string,
  url: string,
  title: string,
  imageRef: 'favicon' | 'letter' | string,  // string = ключ в local.images
  color: string,                              // для режима letter
  order: number
}>

// storage.local (тяжёлое, не синхронизируется)
images: { [imageRef: string]: { data: string /* data URL */, source: 'upload' | 'url', srcUrl?: string } }
```

`imageRef` связывает карточку из `sync` с картинкой в `local`. Фон-картинка хранится
так же — через ссылку на запись в `local.images`.

**Защита квоты sync:** метаданные хранятся компактно; при ошибке квоты
`storage.ts` ловит её, переключает соответствующий блок в `local` и показывает
пользователю уведомление, что синхронизация для этого блока отключена.

## 5. Каскад превью карточки

При рендере `<DialCard>` источник изображения выбирается так:

1. `imageRef` указывает на запись в `local.images` → показываем её. Если запись
   с `source: 'url'` устарела/битая при загрузке → переходим к шагу 2.
2. Если включён скриншот-сервис (см. ниже) и для карточки выбран этот режим →
   показываем скриншот.
3. `imageRef === 'favicon'` или картинка не найдена → фавикон через MV3 favicon API.
4. Фавикон не загрузился → буква (первый символ названия) на фоне авто-цвета
   (детерминированный цвет из URL).

Загрузка по URL: `images.ts` делает `fetch`, конвертирует в data URL, сохраняет в
`local.images` под `imageRef`. Последующие открытия — из кэша, без сети.

**Опциональный скриншот-сервис.** Выключен по умолчанию. В настройках есть
переключатель с честным предупреждением: при включении URL открываемых сайтов
отправляются стороннему сервису скриншотов. Когда включён, в `<CardEditor>`
появляется режим превью «скриншот»; `images.ts` формирует `<img src>` на сервис
(без широких `host_permissions`, без CORS) и кэширует результат в `local`.

## 6. Темы

Три встроенные темы (id фиксированы):

- `light-minimal` — светлый минимализм (белые карточки, мягкие тени).
- `glass-gradient` — матовое стекло на ярком градиенте.
- `dark-neon` — глубокий тёмный фон, сочные акценты.

Тема = набор CSS-переменных (цвета фона, карточек, текста, акцентов, радиусы,
эффекты стекла). Пользователь может создать свою тему (клон встроенной + правки),
переключать активную, и независимо задать фон (цвет / градиент / своя картинка).
Пользовательские темы хранятся в `settings.customThemes`.

## 7. Экспорт / импорт

- **Экспорт:** `backup.ts` собирает полный снимок (`settings` + `dials` +
  использованные `images`/фоны).
  - Если кастомных файлов нет → скачивается `speeddial-backup-YYYY-MM-DD.json`.
  - Если есть → `speeddial-backup-YYYY-MM-DD.zip` через fflate:
    `settings.json` + `images/<ref>.<ext>`.
- **Импорт:** принимает `.json` и `.zip`. Определяет тип по содержимому. Проверяет
  `schemaVersion` и структуру. Показывает предпросмотр (сколько карточек, тем) и
  требует подтверждения перед заменой текущих данных. При несовместимой версии или
  битом файле — понятная ошибка, текущие данные не изменяются.

## 8. Обработка ошибок

| Ситуация | Поведение |
|---|---|
| Битая/недоступная картинка по URL | Каскад фолбэков (§5), без падения |
| Фавикон не загрузился | Буква + авто-цвет |
| Переполнение `storage.sync` | Откат блока в `local` + уведомление |
| Импорт чужого/битого файла | Ошибка с пояснением, данные не трогаем |
| Несовместимая `schemaVersion` | Сообщение, предложение обновить расширение |

## 9. Тестирование

- **Vitest** для модулей логики: `storage` (split sync/local, обработка квот),
  `themes` (применение переменных), `images` (каскад фолбэков, кэш),
  `backup` (round-trip экспорт→импорт для JSON и ZIP). `chrome.*` API мокается.
- **`@testing-library/preact`** для ключевых компонентов: рендер `<DialCard>`
  во всех режимах превью, `<DialGrid>` (порядок после reorder), `<CardEditor>`
  (валидация формы).
- Ручная проверка в Chrome (загрузка распакованного `dist/`): открытие вкладки,
  drag-and-drop, смена темы, экспорт/импорт.

## 10. Вне области первой версии (YAGNI)

- Папки/группы карточек и вкладки разделов.
- Скриншот-сервис **по умолчанию выключен** (сам переключатель и интеграция — в v1,
  но включается только вручную; автоскриншоты всех сайтов без согласия — вне области).
- Виджеты погоды, заметок и т.п.
- Синхронизация картинок между устройствами (только метаданные синхронизируются).

## 11. Структура проекта

```
speeddial/
  manifest.config.ts
  vite.config.ts
  index.html
  src/
    main.tsx
    components/   (NewTab, Clock, SearchBar, DialGrid, DialCard, CardEditor, Settings, ThemePicker)
    lib/          (storage, themes, images, state, backup)
    styles/       (темы, CSS-переменные)
  test/
  dist/           (сборка, грузится в Chrome)
```
